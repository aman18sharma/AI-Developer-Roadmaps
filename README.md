# 🧭 AI Developer Roadmaps

Structured, checkbox-driven roadmaps for becoming a GenAI / Agentic AI developer — built around shipping real projects, not just watching tutorials.

Two tracks live in this repo. Pick the one that matches your goal, or run them back to back.

| Roadmap | Timeframe | Best for |
|---|---|---|
| [📅 GenAI Developer – 90 Days Roadmap](./GenAI%20Developer.md) | 90 days | Going from zero to a working GenAI developer: prompting, RAG, agents, fine-tuning, a deployed portfolio project |
| [🤖 Agentic AI Engineer → FDE Roadmap](./Agentic%20AI%20Roadmap.md) | 6–9 months | Going deeper into agents, MCP, evals, and production — aimed at Forward Deployed Engineer / applied AI engineering roles |

---

## 🎯 Philosophy

Both roadmaps follow the same rules:

- **Build > watch.** Every stage ends in a project, not just a course.
- **Ship in public.** Push to GitHub regularly instead of hoarding work locally.
- **Real projects only.** No throwaway toy demos — everything should be portfolio-worthy.
- **Evaluate, don't guess.** Later stages force you to add evals, tracing, and guardrails before calling something "done."

## 📅 GenAI Developer – 90 Days

A day-by-day plan across three months:

- **Month 1 — Foundations:** LLM basics, prompting, APIs, chat systems, embeddings, vector DBs, RAG
- **Month 2 — Advanced GenAI:** Agents, memory systems, fine-tuning, evaluation & guardrails
- **Month 3 — Production + Portfolio:** Scaling & caching, frontend, a flagship AI Vulnerability Scanner project, and job-application prep

Open [`GenAI Developer.md`](./GenAI%20Developer.md) and check off each day as you go — GitHub renders `- [ ]` as clickable checkboxes.

## 🤖 Agentic AI Engineer → FDE

A four-phase progress tracker for a deeper, longer-horizon path:

- **Phase 1 (Months 1–2):** Engineering foundations + your first framework-free agent
- **Phase 2 (Months 2–4):** RAG from scratch, one framework (LangGraph), real evaluation & tracing
- **Phase 3 (Months 4–6):** One real multi-agent/MCP production project, deployed and CI-gated
- **Phase 4 (Months 6–9):** FDE-style discovery practice, portfolio positioning, interview prep

Each phase ends with an explicit **exit criterion** — a concrete bar to clear before moving on. Open [`Agentic AI Roadmap.md`](./Agentic%20AI%20Roadmap.md) for the full checklist with linked resources.

> 💡 Tip: if you want a live "X of Y tasks complete" progress bar (rather than a static checklist), paste the roadmap into a GitHub **Issue** instead of a plain file — Issues auto-render task-list completion percentages.

## 🚀 How to use this repo

1. **Fork or clone** this repo.
2. Pick a roadmap (or both) and open the file.
3. Check off items as you complete them and commit regularly — your commit history becomes proof of consistency.
4. Treat every "Build:" item as non-optional. These are the checkpoints that turn a checklist into a portfolio.
5. By the end, you should have shipped: a RAG system, an agent, a chat app, and at least one flagship project you can demo and defend.
